AC HRA Portal v29
=================

Manpower requisition / approval update

- Removed the separate Approval page. Approval status is now shown in the
  Manpower requisition table with a Pending / Approved / Rejected filter.
- Added full Department / Section or Group / Position columns, request reason,
  conditions, linked people, and joined / resigned progress to the manpower
  view and Telegram approval content.
- Added optional manual Joined / Hired and Resigned fields for cases where
  Recruitment or Join / Resign data is not linked yet. Linked records still
  take priority automatically.
- Added dropdowns for experience (beginner, semi-skilled, experienced, any,
  etc.) and education level.
- Added a Manpower Requisition Excel round-trip: exported Manpower sheets can
  be imported again, including manual progress and approval status.
- Approval / summary Telegram requests now have a timeout and no longer wait
  for cloud upload after Telegram delivery. Cloud sync continues in the
  background, so the Send button does not remain stuck on Sending.
- GAS v2.8 keeps the no-duplicate approval rule and includes full manpower
  labels plus joined / resigned progress in review and approval result messages.

Deployment
----------

1. Replace the existing portal HTML files with all files in this ZIP.
2. Replace the existing GAS source with ga_attendance_cloud-v29.gs and deploy
   a new version of the existing Web App.
3. No one-click installation is required for this update because it does not
   change the bot credentials or scheduled triggers. Run 一鍵安裝() only for a
   brand-new GAS project or if the existing project has never been installed.
