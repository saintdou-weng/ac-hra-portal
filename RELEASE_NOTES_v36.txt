AC HRA Portal v36
=================

本版補強上一版下載後顯示 0 筆的問題。

1. Maternity／Health Fee／Medical Purchase／Clinic
   - 自動讀取舊雲端完整快照：employees、nursing、healthFees、medicalPurchase、clinic、salaryRecords。
   - 舊快照會轉成目前頁面使用的資料列，保留人數、金額、看診人次與部門摘要。
   - 舊版與新版資料都會依 type 分流，不會把健檢費或醫療採購誤當孕婦人員。

2. Welfare／Certificate／Manpower／Maternity
   - 空的 smart manifest 會繞過空索引，重新讀取舊雲端資料並重建索引。
   - 下載結果新增雲端筆數檢查；若雲端有資料但手機實際讀到 0 筆，會直接顯示錯誤，不會再顯示「下載完成」後默默變成空白。
   - 不會因為手機空資料而自動上傳或覆蓋原本雲端資料。

3. Cache bust
   - 所有 Portal HTML 的 shared/hra-smart-sync.js 更新為 v36，避免手機繼續使用舊版 JavaScript。

部署
----

- GitHub Pages：使用本版 ZIP 內整份 Portal HTML 與 shared 資料夾。
- Apps Script：同時更新 ga_attendance_cloud.gs，部署為新版本；網址維持原本 GAS Web App URL。
- 不需要一鍵安裝，也不需要重新整理 Excel 格式。
- 更新後每個模組只需在手機按一次「下載」測試；若雲端有資料而讀入仍為 0，畫面會顯示實際錯誤，不會再誤報完成。

注意
----

- 先不要按「清除全部」，也不要把空白手機資料重新上傳。
- 舊的 welfare／cert／manpower／maternity 雲端檔案會保留，修正版只做讀取、合併與索引重建。
